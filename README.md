# jmeter-blazedemo-performance-test
My JMeter performance testing project using BlazeDemo demo site.

# Project Contents
BlazeDemo_TestPlan.jmx – Main JMeter test plan

# Config Elements
- HTTP Request Defaults

# HTTP Requests for:
- Launch Home Page
- Find Flights
- Choose Flight
- Purchase Flight

# Listeners:
- View Results Tree
- Summary Report
- Aggregate Report
- Graph Results

# Test Scenario
The test simulates a real user booking process:
- Open the home page
- Select departure and destination
- View available flights
- Choose a flight
- Enter details and confirm purchase
